# Заглушить фоновую проверку версии

## Why

`hermes update` и обновление в десктопе уже заглушены. Осталась пассивная
проверка: при старте CLI `check_for_updates()` делает `git fetch origin main`
и при необходимости ходит в GitHub compare API. Это последнее обращение
наружу, которое агент инициирует сам, — и оно противоречит смыслу форка.

Толку от неё всё равно нет: на целевой машине `.git` в комплекте отсутствует,
проверка молча падает, а на сборочной — предлагает обновиться командой,
которая теперь отказывает.

## What Changes

`check_for_updates()` в `hermes_cli/banner.py` возвращает `None` сразу.
`None` там уже значит «проверка неприменима» — так обходятся с docker и apt,
и все три вызывающих места это понимают: баннер, бейдж в TUI и REST-эндпоинт
дашборда `/api/hermes/update/check`.

## Impact

- Capability `update-lockout`, одно новое требование.
- Файл: `hermes_cli/banner.py`.
- Кэш `.update_check` в `HERMES_HOME` перестаёт писаться; существующий файл
  просто не читается.
