# update-lockout — дельта требований

## ADDED Requirements

### Requirement: Фоновая проверка версии не выполняется

Пассивная проверка наличия обновлений ДОЛЖНА возвращать «неприменимо», не
обращаясь к сети.

#### Scenario: Запуск CLI

- **Given** Hermes запускается на любой машине
- **When** отрабатывает проверка обновлений при старте
- **Then** ни `git fetch`, ни запрос к GitHub не выполняются
- **And** ни баннер, ни бейдж в TUI не показывают отставание от апстрима

#### Scenario: Запрос через дашборд

- **Given** дашборд запрашивает `/api/hermes/update/check`
- **When** запрос обрабатывается
- **Then** ответ означает, что проверка неприменима
- **And** эндпоинт не отвечает ошибкой
