# update-lockout — дельта требований

## MODIFIED Requirements

### Requirement: Десктоп показывает заглушку вместо обновления

Экран обновлений в desktop-приложении ДОЛЖЕН показывать причину отказа
и гифку — на том экране, куда пользователь попадает, а не в отдельном окне,
до которого нет пути.

#### Scenario: Пользователь открывает экран обновлений

- **Given** desktop-приложение запущено
- **When** пользователь открывает раздел обновлений
- **Then** показывается сообщение о недоступности обновления
- **And** под текстом видна гифка
- **And** кнопка установки не предлагается

#### Scenario: Гифка берётся из сборки

- **Given** целевая машина не имеет доступа в интернет
- **When** отображается экран обновлений
- **Then** гифка загружается из файла внутри приложения
- **And** внешних запросов ради неё не делается
