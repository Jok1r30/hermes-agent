# chat-timing — дельта требований

## ADDED Requirements

### Requirement: Время ответа сохраняется вместе с сообщением

Длительность хода ДОЛЖНА сохраняться на бэкенде вместе с ответом агента,
чтобы не зависеть от того, наблюдал ли интерфейс этот ход.

#### Scenario: Ответ получен

- **Given** пользователь отправил сообщение
- **When** агент завершил ответ
- **Then** длительность хода сохраняется вместе с сообщением

#### Scenario: Сессия открыта заново

- **Given** сессия с сохранёнными ответами
- **When** она открывается заново
- **Then** у каждого ответа показано то же время, что и при получении

#### Scenario: Ответ из старой сессии

- **Given** ответ, сохранённый до появления этой возможности
- **When** сессия открывается
- **Then** время не показывается
- **And** интерфейс не показывает ноль или заглушку

### Requirement: Время видно в чате

Время ДОЛЖНО быть читаемым, а не теряться в интерфейсе.

#### Scenario: Пользователь смотрит на ответ

- **Given** ответ агента с известной длительностью
- **When** пользователь смотрит на сообщение
- **Then** время видно без наведения курсора и без открытия меню
