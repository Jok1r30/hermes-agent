# update-lockout

Обновление отключено во всех точках входа: форк держит агента вне сети,
а комплект пересобирается на другой машине.

## Requirements

### Requirement: CLI отказывает в обновлении

Команда `hermes update` ДОЛЖНА завершаться предупреждением, не выполняя никаких
действий над деревом исходников.

#### Scenario: Пользователь запускает обновление

- **Given** Hermes установлен из офлайн-комплекта
- **When** выполняется `hermes update`
- **Then** печатается сообщение о том, что обновление недоступно и идёт через пересборку комплекта
- **And** дерево исходников не изменяется
- **And** код возврата отличен от нуля

#### Scenario: Обновление с флагами

- **Given** пользователь передаёт флаги вроде `--check`, `--yes` или `--force`
- **When** выполняется `hermes update` с ними
- **Then** поведение то же самое — предупреждение и выход
- **And** ни один флаг не обходит заглушку

### Requirement: Десктоп показывает окно вместо обновления

Запрос обновления из desktop-приложения ДОЛЖЕН открывать окно с тем же текстом,
что печатает CLI, и с гифкой.

#### Scenario: Запрос обновления из интерфейса

- **Given** desktop-приложение запущено
- **When** приходит запрос на применение обновления
- **Then** открывается окно с сообщением о недоступности обновления
- **And** в окне показана гифка
- **And** обновление не запускается

#### Scenario: Гифка берётся с диска

- **Given** целевая машина не имеет доступа в интернет
- **When** открывается окно-заглушка
- **Then** гифка загружается из файла внутри приложения
- **And** приложение не делает исходящих запросов, чтобы её показать

### Requirement: Проверка обновлений не предлагает обновиться

Проверка наличия обновлений ДОЛЖНА сообщать, что обновлений нет, чтобы
интерфейс не предлагал действие, упирающееся в заглушку.

#### Scenario: Приложение проверяет обновления

- **Given** desktop-приложение запущено
- **When** выполняется проверка обновлений
- **Then** результат сообщает об отсутствии обновлений
- **And** запрос на github.com не отправляется

### Requirement: Фоновая проверка версии не выполняется

Пассивная проверка наличия обновлений ДОЛЖНА возвращать «неприменимо», не
обращаясь к сети.

#### Scenario: Запуск CLI

- **Given** Hermes запускается на любой машине
- **When** отрабатывает проверка обновлений при старте
- **Then** ни `git fetch`, ни запрос к GitHub не выполняются
- **And** ни баннер, ни бейдж в TUI не показывают отставание от апстрима

#### Scenario: Запрос через дашборд

- **Given** дашборд запрашивает `/api/hermes/update/check`
- **When** запрос обрабатывается
- **Then** ответ означает, что проверка неприменима
- **And** эндпоинт не отвечает ошибкой
